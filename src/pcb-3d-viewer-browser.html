PCB 3D Viewer in the Browser

ECAD Forge shows interactive 3D board views from supported Altium and KiCad PCB files. The parser runs locally in your browser with no upload.

Open a PCB file Try a sample board

Local browser parsing · No account · No server upload

Use Cases

  • Check board outline, scale and component placement quickly.
  • Review 3D context before a documentation or assembly pass.
  • Inspect open-hardware boards from GitHub links.
  • Switch between PCB, 3D, BOM and diagnostics tabs.

FAQ

Does 3D require upload? No. Supported board data is parsed locally.

Can I make nicer images? Use PCB Styler for documentation-oriented board renders.

What files work? Selected .PcbDoc and .kicad_pcb files are supported.
