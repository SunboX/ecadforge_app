# Dark mode acceptance

- Match the supplied dark references with blue-black surfaces, cool borders, readable pale text, orange active controls, and teal secondary actions.
- Cover the landing page, schematic, PCB, 3D, BOM, diagnostics, sidebars, and transient controls.
- Default to the system preference without storing an override; use light if no supported dark preference exists.
- Follow system changes until the user chooses a mode manually.
- Persist either manual choice across browser sessions, taking precedence over the system.
- Apply appearance before the main app loads, and remain usable when browser storage is unavailable.
- Provide a translated switch operable with keyboard and assistive technology.
- Preserve loaded documents, geometry, selection, and viewport when switching.
- Keep the toolbar usable on narrow screens and retain the existing light appearance.
